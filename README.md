# Сокращатель URL

Сайт на **.NET 10** (Blazor Server): длинную ссылку превращает в короткую `/s/{код}`, хранит её в **MariaDB** и считает переходы.

Строка подключения уже прописана в `appsettings.json`. Достаточно поднять базу и запустить проект.

## Что нужно

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- [Docker](https://www.docker.com/products/docker-desktop/) — для MariaDB

## Запуск

В корне репозитория:

```bash
docker compose up -d --wait
dotnet run
```

Откройте [http://localhost:5218](http://localhost:5218). При старте приложение само создаёт базу `ab1` и накатывает миграции.

Остановить MariaDB: `docker compose down`.

Своя база вместо Docker — поменяйте `ConnectionStrings:Default` в `appsettings.json` и запускайте только `dotnet run`.

## Как пользоваться

1. **Главная** — вставьте абсолютный URL (`http://` или `https://`), нажмите **Сжать**. Появится короткая ссылка.
2. **Ссылки** (меню слева) — таблица: длинный URL, короткий URL, дата, число переходов, **Редактировать** и **Удалить**.
3. Откройте короткую ссылку в новой вкладке — счётчик переходов вырастет (обновите страницу «Ссылки»).

Код ссылки случайный, его нельзя угадать по порядку вроде `1, 2, 3`.

## Тесты

MariaDB не нужна:

```bash
dotnet test
```
